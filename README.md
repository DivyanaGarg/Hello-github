# Hello-github
My first github repository.
I am learning how to use github step by step.

Git commands from remote to local -> git clone (paste https link)

To check if changes -> git status 
1. untracked -> new files
2. modified -> changed files
3. unmodified -> unchanged files (committed files)
4. staged -> files ready to be committed (added files but not committed)

Two step process to save the modified file ->
git add file_name (to add all files -> git add .)
git commit -m "some message"

Upload local content to remote repo -> git push origin main
